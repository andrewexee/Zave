**Zave** es una aplicación inteligente de lista de la compra y comparador de precios diseñada para optimizar el ahorro y la logística del hogar. Centraliza precios de múltiples supermercados y toma decisiones inteligentes por el usuario basándose en el coste y la eficiencia.

> *"En inglés ahorrar se dice 'save'... ¿O no lo Zave?"*

---

## ✨ Características Principales

* **📦 Gestión de Inventario:** Catálogo completo de productos con descripción, peso y categorías con códigos de color.
* **💰 Comparador de Precios:** Visualización en tiempo real de los precios de un mismo producto en diferentes establecimientos.
* **🧠 Algoritmo de Desempate (Smart-Choice):** Si un producto tiene el mismo precio mínimo en varios sitios, Zave lo asigna automáticamente al supermercado donde ya tienes más artículos para minimizar tus desplazamientos.
* **🔐 Control de Acceso (RBAC):** Sistema de roles integrado (`User`, `Editor`, `Admin`) para proteger la integridad de los datos.
* **📱 Mobile First & PWA:** Diseño optimizado para iOS/Android con gestión de áreas seguras (`safe-area-inset-top`).
